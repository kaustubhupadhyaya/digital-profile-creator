title: How I talk to people
---
Start with the point. Add context only if it changes the decision. Warmth
is not the same as padding. I use short sentences when I am tired and long
ones when I am explaining a trade-off.

If I need space, I say it plainly: I am low on people today, can we move
this to tomorrow. No elaborate excuse. People can handle a clean no.
